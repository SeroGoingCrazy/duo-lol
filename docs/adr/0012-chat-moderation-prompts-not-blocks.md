# 聊天审核以提示和举报为主，不拦截消息；管理员只看举报快照

聊天只在互选后开放（ADR-0011），双方已经同意认识，所以联系方式在聊天里允许发（简介里仍然不允许）。审核的目标是辱骂、骚扰和钓鱼链接。做法照 Tinder 的"确定要发吗？"和"这句话冒犯你了吗？"：发送方命中辱骂词表或发了不在白名单里的链接时提示一次，不拦截；接收方看到命中词表的消息时，下方给一个直接举报的入口。不做自动拦截，因为词表误伤多（游戏黑话、英雄名），拦错了比放过一句脏话更伤体验；真正的处理靠举报和人工。

举报一条消息时自动附上它和前后各 10 条作为快照。管理员**只能看快照**，不能打开任何对话，这是对会员隐私的承诺，也写进隐私政策。管理员可以暂停一个会员的聊天（不影响他的互选和滑卡），沿用 3 人举报自动暂停推荐的规则。取消互选或注销后，对话保留 30 天再删除，只为处理这段时间里的举报；快照跟着举报保存到处理完成后 90 天。

代价：没有机器审核，会员多了以后人工队列会变长；那时再考虑接入审核模型，但它只能产生"提示"和"进人工队列"，不能直接删消息或封号。
