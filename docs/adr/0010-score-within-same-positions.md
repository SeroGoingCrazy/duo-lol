# 搭配评分只和同样两个位置的组合比

原来的搭配评分把一个组合的预测胜率放进推荐池里所有可双排组合的分布里看百分位，不管位置。Jacky 指出（2026-10-21）这样不公平：打野+中单的组合应该和别的打野+中单组合比，而不是和随便两个位置的组合比。不同位置分配的预测胜率分布本来就不一样（英雄分和组合加成都按位置统计），混在一起比，某些位置分配天生偏高或偏低，分数反映的是位置而不是搭配。

所以 `data/score_scale.py` 按位置对（不分先后，打野+中单 和 中单+打野 是同一对）分别拟合正态分布的均值和标准差，组合按它的建议位置分配去查对应的分布。抽样时每个位置对要 300 个组合，最多预测 3000 个；某个位置对少于 30 个样本时标准差太不稳（误差超过约 13%），这一对退回用全部组合的分布，API 用 `score_by_roles: false` 标出来，页面上就不写“比 x% 的打野+中单组合更好”，只写“比 x% 的组合更好”。

英雄组合的全服胜率（组合加成）本来就只统计同一对位置上的两个英雄，这次不变。牌堆排序仍按预测胜率（ADR-0006），所以不同位置分配的卡片之间，评分可能不是单调的。旧的 `score_scale.json` 没有按位置的拟合，API 启动时当作没有，在后台重新拟合。
