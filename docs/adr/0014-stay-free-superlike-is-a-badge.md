# 继续不收费；超级喜欢免费，每天 1 次，只是一个标记，不改变排序

Tinder 靠付费功能赚钱：看谁喜欢你、撤销、无限喜欢、超级喜欢、Boost 买曝光。前两项我们已经免费给了（PRD-v2）。v3 仍然不收费（Jacky，2026-10-22）：搭子池小，任何让付费的人更容易被看到的功能都会让免费会员的牌堆变差；Boost 和按付费排序也违反"排序依据必须能写成理由"的红线（ADR-0013）。

超级喜欢保留，因为它传递了真实的信号（"我特别想和你打"），对方据此回滑的意愿更高。它免费、每人每天 1 次；对方在"喜欢我的人"里看到它排在最前并带标记，牌堆里刷到你时卡片上也有标记。它**不改变**你在对方牌堆里的位置：按 ADR-0013，已经喜欢他的人回滑概率本来就是 1，会自然排前，不需要再给超级喜欢额外加权。

以后如果要收费，只能卖不影响别人牌堆的东西（比如外观），并且要先核对 Riot 开发者政策对收费的要求。
